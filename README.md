# Flutter Game Dev Simple Example

This example demonstrates a minimal Flutter game concept using Dart. It showcases how Flutter's widget system can be used to build interactive game UIs, with a simple score counter that increments on button tap. This highlights Flutter's potential for creating engaging user experiences in games.

## Language

`dart`

## How to Run

1. Ensure you have Flutter SDK installed.
2. Save the code as `main.dart`.
3. Run `flutter run` in the terminal in the same directory.
